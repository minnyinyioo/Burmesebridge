# BurmeseBridge 产品与 UI/UX 系统

## 1. 技术与许可证决策

BurmeseBridge 保留现有 Next.js、React、Supabase 与 Vercel 架构，不接入第二套整站运行时、认证或数据库。

| 层级 | 采用方案 | 许可证/原则 |
| --- | --- | --- |
| 应用框架 | Next.js App Router | 保留现有架构 |
| 数据、认证、文件 | Supabase | 保留现有 API、RLS 与数据 |
| UI 源码基础 | shadcn/ui + Radix UI | MIT，可商用、可修改；保留许可证声明 |
| 图标 | Lucide | ISC，可商用 |
| 样式 | Tailwind CSS + 语义化设计变量 | MIT；禁止新增页面级颜色体系 |
| LMS 参考 | Frappe Learning / CourseLit | 仅参考信息架构；AGPL 项目代码不复制进本站 |

不直接嵌入完整 LMS 的原因：它会造成两套账号、权限、数据库、支付、国际化和后台，后期维护成本高于继续开发现有系统。课程能力在现有数据模型上模块化实现。

## 2. 整站页面类型

所有页面必须归入以下一种模板，不再自由拼装页面外壳：

1. `Marketing`：首页、会员、产品介绍。
2. `Directory`：新闻、工作、视频、课程、搜索结果。
3. `Detail`：新闻详情、职位详情、课程详情、帖子详情。
4. `Workspace`：课堂、作业、测验、创作与提交。
5. `Account`：个人资料、安全、通知、订单、学习记录。
6. `Admin`：总览、表格、审核、编辑器、日志。
7. `Legal`：条款、隐私、社区规则、安全与数据删除。
8. `System state`：加载、空状态、无权限、404、500、离线。

## 3. 全局设计规则

- 品牌主色只使用 `--brand` 及其语义派生色；错误、警告、成功使用状态变量。
- 页面最大宽度、间距、圆角、阴影、标题层级由共享组件控制。
- 中文、缅文、英文分别测试；缅文字号和行高不得继承中文的紧凑值。
- 所有交互必须有 hover、focus、disabled、loading、success、error 状态。
- 图标来自 Lucide 或已核准的真实品牌图标；不使用 emoji 充当产品图标。
- 移动端先保证任务完成，再增强桌面布局；不得靠横向滚动隐藏主要操作。
- 深浅色均使用语义变量，不在组件中写死白色背景或绿色文字。

## 4. LMS 产品结构

```text
课程首页
└─ 课程详情
   ├─ 教师 / 目标 / 对象 / 许可证与来源
   └─ 章节
      └─ 课时
         ├─ 视频 + 字幕 + 正文
         ├─ 词汇 + 讲义 + 附件
         ├─ 随堂练习
         └─ 作业提交
```

学习闭环：选课 → 试看/购买 → 学习 → 保存最后位置 → 作业/测验 → 教师反馈 → 完成率 → 结课考试 → PDF 证书。

后台编辑闭环：课程 → 章节 → 课时三级编辑；同级拖动排序；发布前校验视频、字幕、附件、来源与许可证；所有发布和批改写入审计日志。

## 5. 数据模块（按迁移顺序）

1. `courses`：等级、技能、封面、教师、学习目标、适用对象、人数与发布状态。
2. `course_sections`：课程章节、排序。
3. `course_lessons`：视频、正文、字幕、词汇、讲义、试看和时长。
4. `lesson_attachments`：PDF 作业与讲义，私有存储和签名下载。
5. `lesson_progress`：最后播放位置、完成状态、连续学习记录。
6. `assignments/submissions/grades`：提交、批改、成绩与评语。
7. `quizzes/questions/attempts`：六类题型和答题记录。
8. `certificates`：课程、考试、证书编号与 PDF 快照。
9. `resource_licenses`：作者、来源 URL、许可证、版本、核验日期。

## 6. 迁移顺序与验收

### Phase A：基础系统

- 统一页面容器、标题、卡片、表单、表格、对话框和状态组件。
- 清理行内样式和重复 CSS；建立中文、缅文、英文排版基线。
- 完成键盘焦点、对比度、移动端导航与深浅色回归。

### Phase B：课程系统

- 课程目录、详情、课堂、作业、测验、进度、证书、三级后台编辑器。
- 每个功能必须连接真实数据库；占位按钮不得进入生产。

### Phase C：内容与社区

- 新闻、工作、视频、论坛统一目录与详情模板。
- 媒体、互动、举报、审核、反馈使用同一状态和权限规范。

### Phase D：账户与后台

- 账户设置使用分组导航与按需展开表单。
- 后台统一侧栏、指标卡、筛选表格、编辑器、确认与操作结果。

### Phase E：公开验收

- 三种语言 × 深浅色 × 手机/平板/桌面回归。
- 注册、认证、找回密码、支付、权限、RLS、上传和审计安全测试。
- Lighthouse、无障碍、SEO、404/500、监控和备份恢复演练。
